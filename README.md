# Bomba Certa v7.9 — interface de preço simplificada

## Alterações
- Removido o botão **GPS** das fichas dos postos.
- Mantido apenas **Ver rota**, para evitar duas ações com finalidade semelhante.
- Nos popups do mapa, **Abrir GPS** foi substituído por **Ver rota**.
- Junto ao preço passa a aparecer explicitamente o combustível selecionado.

## Exemplo
`1,788 €`
`Gasóleo simples · por litro`

Assim o utilizador percebe imediatamente a que combustível corresponde o preço apresentado.

- Removidos também os botões «Abrir GPS» do painel de rota; a navegação fica concentrada em «Ver rota».
