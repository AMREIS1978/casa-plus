# Bomba Certa v4.6 — fotografia corrigida

A fotografia do utilizador deixa de poder ficar em branco.

Correções:
- fallback imediato no topo e no perfil;
- fotografia real substitui o fallback assim que o perfil é carregado;
- recuperação automática se o URL da imagem falhar;
- cache-busting para evitar fotografia antiga;
- ao alterar a fotografia, a nova imagem é mostrada imediatamente no topo e no perfil.

Mantém todas as funcionalidades e desempenho da v4.5.
