# Bomba Certa v8.1 — Registo simples e responsivo

Melhorias:
- registo em 4 passos claros;
- username sugerido e normalizado automaticamente;
- validação visual imediata por campo;
- password com medidor e Mostrar/Ocultar;
- sem checkbox obrigatório;
- mensagens específicas para username/email já existentes;
- recuperação automática quando uma primeira criação foi concluída mas a resposta se perdeu;
- entrada automática após criar a conta;
- novo responsive para desktop, tablet, telemóvel e ecrãs pequenos.

A arquitetura segura atual `public-register` + `public-login` foi preservada.
