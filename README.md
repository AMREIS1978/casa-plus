# Bomba Certa v4.0 — nível/status visível no perfil

## Perfil
O nível/status passa a aparecer imediatamente por baixo do nome do utilizador, num badge próprio.

Exemplos:
- Nível: Novato
- Nível: Explorador
- Nível: Guia
- Nível: Especialista
- Nível: Embaixador
- Nível: Editor de confiança
- Nível: Administrador

Os pontos continuam privados e aparecem apenas ao próprio utilizador.
