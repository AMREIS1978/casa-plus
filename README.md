# CASA+ v0.6 — Combustíveis validados pela comunidade

## Novo nesta versão
- cada preço de combustível pode ser confirmado pelos utilizadores;
- possibilidade de marcar um preço como incorreto;
- possibilidade de introduzir imediatamente um novo preço;
- reporte de posto fechado;
- reporte de combustível indisponível;
- contagem de confirmações e discordâncias;
- classificação simples de confiança: Muito fiável / Fiável / A confirmar / Desatualizado;
- atualizações em tempo real via Supabase Realtime;
- mantém localização voluntária, mapa, pesquisa ativa de postos e ordenação pelos preços disponíveis;
- interface em português de Portugal.

## Fonte oficial
A aplicação está preparada para receber uma fonte oficial/base por posto.
A integração automática com a DGEG deve ser feita através do serviço de Partilha de Informação após obtenção das respetivas credenciais e condições de utilização.

## Privacidade
A localização do utilizador é pedida apenas quando este decide procurar postos próximos.
Não é guardada como histórico pessoal. Os reportes guardam apenas a localização pública do posto.
