# CASA+ v0.4.1 — Português de Portugal

Esta versão mantém as funcionalidades da v0.4 e revê a interface para português de Portugal.

## Alterações
- textos visíveis revistos para português de Portugal;
- mensagens de erro de autenticação traduzidas e simplificadas;
- estados das faturas apresentados em português;
- “stock” apresentado ao utilizador como “existências” / “quantidade disponível”;
- compras, receitas, despesas, consumo de produtos e eliminação de faturas mantidos;
- dados continuam reais e começam a zero.

## Nota sobre emails de registo
Para registos públicos é necessário configurar um servidor SMTP próprio no Supabase.
