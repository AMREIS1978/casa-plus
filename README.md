# Bomba Certa v9.2 — Navegação premium

## Objetivo
Melhorar os botões de navegação inferior para uma experiência mais elegante, intuitiva e rápida de usar, inspirada nas boas práticas das melhores apps móveis.

## O que foi melhorado
- barra de navegação flutuante com aspeto mais premium;
- botões com hierarquia visual clara;
- estado ativo muito mais evidente;
- ícones dentro de cápsulas para leitura imediata;
- labels mais curtas e mais claras: **Mapa, Abastecer, Viagem, Análise, Perfil, Admin**;
- targets de toque maiores, mais confortáveis no telemóvel;
- comportamento responsivo em PC, tablet e smartphone;
- navegação continua fixa e sempre acessível.

## Critérios de UX aplicados
- navegação persistente entre áreas principais;
- labels curtas e perceptíveis;
- diferenciação clara entre separadores ativos e inativos;
- menos ruído visual;
- maior facilidade de reconhecimento do que memorização.
