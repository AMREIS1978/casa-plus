# Bomba Certa v9.3 — Interface polida

## Melhorias principais
- experiência refinada em PC, tablet e telemóvel;
- os marcadores do mapa passam a mostrar os preços reais disponíveis por combustível;
- o combustível selecionado fica destacado também no popup do mapa;
- scroll horizontal dos combustíveis mantém-se, mas o scroll vertical da página continua natural;
- scrollbar horizontal fina e visível para indicar que existem mais combustíveis;
- mapa sticky em desktop mantém-se;
- cartões e painéis com espaçamento, sombras e bordas mais suaves;
- novo segundo espaço de publicidade, claramente identificado e sem interromper os resultados.

## Publicidade
Existem agora pelo menos dois pontos publicitários na página principal:
1. novo slot horizontal entre resultados e comunidade;
2. slot premium já existente mais abaixo.

## Mapa
Ao tocar/clicar num posto, o popup apresenta os preços conhecidos de vários combustíveis e permite abrir a rota.
