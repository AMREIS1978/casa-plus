# CASA+ v0.2 — dados reais

Esta versão está ligada ao projeto real Supabase `casa-plus`.

## Estado inicial
Todos os indicadores começam a 0:
- receitas 0 €
- despesas 0 €
- saldo 0 €
- faturas 0
- produtos 0
- stock 0
- locais 0

## Já funcional
- criação de conta / login
- família doméstica criada automaticamente
- movimentos reais guardados no Supabase
- dashboard calculado a partir dos movimentos reais
- upload privado de faturas PDF/JPG/PNG
- contadores reais de produtos, stock e locais
- RLS ativo em todas as tabelas

- comparação de preços / promoções
- combustível por localização
